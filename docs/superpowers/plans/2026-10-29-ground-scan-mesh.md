# Ground Scan Mesh Export Implementation Plan

**Approved goal:** Trial constrained triangulation between adjacent LiDAR scan lines to reduce ground-map strip gaps, with reproducible cached-keyframe output for review. Preserve matching, original measurements, service fields and existing grid/hole-fill behavior. This trial does not promise to reconstruct entirely unobserved terrain or remove every internal hole.

**Architecture:** A ROS-independent `GroundMeshRasterizer` accepts one cached deskewed scan, its projection indices and ground classification, configured output-ring range, and final world pose. Only adjacent row/azimuth cells form triangles, including the azimuth seam. Require three finite ground vertices, valid geometry, distance-adaptive edge limits, a configurable range-discontinuity limit and a world-frame slope limit. Rasterize accepted triangles directly at global XY grid centers; do not retain a global triangle mesh. Deduplicate samples within each frame; accumulate height layers across frames without averaging distinct levels. Append only resolved mesh samples missing from the global measured-ground cells. Existing `BuildGroundGrid` remains the final single-layer/hole-fill stage.

**Configuration:** Add mapping-only `map_save.ground_mesh` with `enable` (C++ default false, YAML true for this trial), `max_edge_length`, `edge_length_per_meter`, and `max_range_ratio`. Mesh slope and height-layer tolerance reuse existing ground-grid slope/height settings. Use the resolved save-service/config ground_resolution; require a positive value when mesh ground export is requested, regardless of the grid switch. Enable only for Current/RingPlane export with its projection cache; unsupported modes fail before prior artifacts are replaced, rather than silently skipping mesh. Thresholds are initial trial values and must be recorded in the comparison output.

**Geometry interface:** `GroundMeshOptions`, `GroundMeshStatistics`, and a non-copyable PImpl `GroundMeshRasterizer` in `include/lio_sam/ground_mesh.h` / `src/ground/ground_mesh.cpp`. Constructor validates options. `AddFrame(scan, projection_indices, classification, rows, columns, GroundRingRange, Eigen::Matrix4f map_from_scan)` validates dimensions/indices and streams samples. `AppendMissingSamples(Cloud* measured_global_ground)` returns appended count and does not change existing points. `statistics()` reports frames/candidate/accepted/rejected triangles and raster samples. A per-frame world-cell map prevents triangle overlap from inflating votes; per-cell height modes count one vote per frame, with ambiguous modes omitted. Layer span must remain bounded by the configured height tolerance.
